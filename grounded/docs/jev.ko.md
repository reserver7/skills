# Jev (선택 기능)

[English](jev.md) | **한국어**

Jev는 설치되지 않으며 setup에서 호출하지 않습니다. 각 호스트에서 제공자의 최신 안내에 따라 공식 Jev MCP 연결을 별도로 구성하세요. 인증 정보는 이 저장소에 두지 않습니다. Jev 없이도 환경을 사용할 수 있습니다.

실제로 해결되지 않은 선택지에 대해 사용자가 평가를 요청하거나 허가한 경우에 사용합니다. 선택이 정말 모호하면 스킬·워크플로 경로를 비교하는 데도 쓸 수 있습니다. 확인된 사실, 불확실성, 가능한 대안과 평가 기준을 제공합니다. 엔드포인트를 추측하거나 스킬에 자격 증명을 넣지 말고 실제 평가 도구와 스키마를 확인하세요. Jev는 조언을 제공하며 범위와 동작 결정은 사용자가 맡습니다.

모든 편집을 분류하거나 변경 없는 평가를 반복하고, 구현을 승인하거나 테스트·보안 검토를 대신하는 데 Jev를 쓰지 마세요. 결과가 무엇을 바꿨는지 또는 바꾸지 않았는지 설명합니다. 의미 점수나 확률은 정확성을 보장하지 않습니다. 절감 효과를 주장하기 전에 Jev를 사용하지 않은 실행과 추가 토큰 및 지연 시간을 비교해야 합니다.

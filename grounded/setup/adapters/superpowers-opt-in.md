## Grounded opt-in

Follow this skill for the requested task or an explicitly selected Superpowers workflow. Keep Grounded's default workflow for other work. In a selected workflow, when the host's skill tool cannot open a follow-on explicit skill, read its installed `SKILL.md` and relevant bundled references directly.

Keep one active implementation plan for the change. A supporting skill such as worktree setup, debugging, TDD, review, or branch finishing can work with the existing plan. To replace a plan, confirm the switch if the user's intent is unclear. Record the previous plan and its status, agreed requirements, failing evidence and unresolved choices, and the new active plan. Continue from the new plan and retain the old artifact for history.

Use worktrees only when isolation is needed. Choose one execution path. Use subagents only with explicit authorization and host support. Keep existing authorization requirements for commits, pushes, publication, and destructive cleanup.

---
name: web-design-guidelines
description: Use whenever asked to review, audit, or assess an existing web page or UI for usability or accessibility. Apply the Vercel Web Interface Guidelines to the requested scope.
---

Use the requested files or changed user flows as the review scope. Read the installed Vercel Web Interface Guidelines at `references/command.md` and apply the relevant checks alongside project requirements.

Use Grounded's managed Playwright CLI when the review needs browser evidence, such as keyboard navigation, focus visibility and restoration, or zoom and reflow. Report actionable findings with file and line, observed impact, and a suggested correction. Identify any requested runtime checks that could not be exercised.

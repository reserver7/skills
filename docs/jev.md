# Jev (optional)

Jev is not installed or called by setup. Configure the official Jev MCP connection separately in each host using the provider's current instructions; keep credentials outside this repository. The environment works without it.

Use when the user requests evaluation, or authorizes it for a particular task with real unresolved choices. A focused request contains confirmed facts, uncertainty, allowed choices and explicit evaluation criteria. Discover the actual available evaluate tool and its schema instead of guessing an endpoint or embedding an API credential in a skill.

Do not use Jev to classify every edit, repeat unchanged evaluations, approve implementation, or stand in for tests/security checks. Explain what the result changed, or that it changed nothing. Semantic scores/probabilities are not correctness guarantees. Compare incremental tokens/latency against a run without Jev before claiming savings.

Provider: https://typesafe.ai/
